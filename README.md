## 🔎 SEO e publicação

O site é HTML estático, multipágina e indexável. Cada página possui URL canônica, título e descrição próprios, links internos e dados estruturados adequados ao conteúdo. O pacote também inclui `sitemap.xml`, `robots.txt`, `llms.txt`, `llms-full.txt`, `CNAME`, `.nojekyll` e auditoria de SEO.

A V489 usa **estrutura de save 178** e documenta o **banco oficial revisão 816 / modelo 7**. As capturas editoriais são imagens reais do jogo obtidas na V487 e continuam identificadas como tal, sem serem apresentadas como screenshots de uma versão posterior.

## 🚀 GitHub Pages

Esta edição é propositalmente **flat**: todos os arquivos ficam na mesma pasta. Extraia `site-V489.zip`, selecione todo o conteúdo e envie para a raiz do repositório configurado no GitHub Pages.

O domínio personalizado já está definido em `CNAME` como `sobre.goooool.net`.
